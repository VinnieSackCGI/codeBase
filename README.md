# EXConnect Plugins Solution  

The EXConnect Plugins Solution is a Visual Studio Pro C# solution that houses all the plugins developed for the ECA's EXConnect application. The solution contains projects that implement the various plugins but also includes a Desktop Interface project. This Desktop Interface project type tries to replace the Plugin Profiler which, at the time of development, could not be launch into any of the DoS environments due to security lockdows. The Desktop Interface is not the same as debugging the code in real-time, but allows to interact directly with the Dataverse instance to test relevant logic and algorithms. At the moment, there are no Unit Tests projects due to the lack of time for implementation. This should be considered at a later date for completeness.

## Introduction
To date, the Power Platform only supports up to the .Net Framework 4.7.1 and it is expected to change in the future, at which time, the projects shold rebuild under the new Framework Library. 

The projects within the solution are as follow.

- ***Portal Plugins*** The project contains the plugins related specifically to the Portal operation such as the manamengent of Users into Teams to assign the specific Web Roles. It also deals with the interaction of the Portal into SharePoint sites and specifically the Support Documents folders. 

- ***Portal Plugins Desktop Runner*** The project is intented to be used to debug the plugins my replicating the Plugin Execution structure. This allows to for debugging the plugins as it was in real-time by using the objects generated by the TracingService used in the er in the Plugin classes..  a set of methods, within the Program file, that allows for testing the Portal Plugins logic against a real instance of Dataverse. This is no substitue for the CRM Profiler but, as stated in the introduction, the profiler cannot be used in the current environment.

- ***EXConnect Plugins*** The project contains the plugins associated with the non-portal side of ECA's application. Amonng the plugins are the Association of Account and Appropriations as well as the Assignment of User Security Roles based on the team membership.

- ***EXConnect Plugins Desktop Runner*** This project contains a set of methods, within the Program file, that allows for testing the EXConnect Plugins logic against a real instance of Dataverse. This is no substitue for the CRM Profiler but, as stated in the introduction, the profiler cannot be used in the current environment.

- ***Plugins Common Library*** This project contains the base classes and methods used by both the EXConnect and Portal plugins projects. This is s Shared Library project and as such it will be atuomatically compiled as a separate DLL and used by any project that needs it. However, since Power Apps does not currently allow for mutilple assemblies, a library merger (ILMerge) is used to combine the main project and the Shared Library into a single assemby before it is deployed.
